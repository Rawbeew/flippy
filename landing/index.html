what's inside

automatic failover

provider returns 429? next one picks up mid-request. no dropped requests.

semantic caching

near-duplicate prompts hit cache instead of burning api calls. tf-idf cosine matching, stdlib-only.

quota-aware routing

tracks remaining free-tier quotas. routes away from exhausted providers before hitting the limit.

multi-key rotation

multiple keys per provider. rotates on 401 (revoked) and 429 (exhausted). all keys tracked in sqlite.

usage dashboard

openai-compatible

works with any client that speaks the openai chat completions format. langchain, openai sdk, curl, anything.
