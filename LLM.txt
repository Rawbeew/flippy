# flippy — LLM.txt

flippy is a multi-provider LLM failover router with an agent harness.
Pure Python stdlib for the core; optional litellm for multimodal.

## What it does
- Routes chat requests across 5 free-tier providers with automatic failover
- Semantic response cache (TF-IDF cosine, SQLite-backed)
- Per-provider quota tracking with cooldown before rate-limit hits
- Multi-key rotation per provider
- Agent loop with role-based tool restrictions (scout/builder/verifier/reporter)
- Eval suites and load-testing tools
- 116 unit tests including failure injection

## Key commands
- `python src/ai_failover.py "prompt"` — one-shot chat with failover
- `python -m src.loomweaver providers` — list providers
- `python -m src.loomweaver agent "<goal>"` — run the agent
- `python -m src.loomweaver eval --suite <name>` — run evals
- `docker compose up && curl localhost:8080/health` — containerized
