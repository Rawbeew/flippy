# flippy — LLM.txt

flippy is a multi-provider LLM failover router with an agent harness.
Pure Python stdlib for the core; optional litellm for multimodal.

## What it does
- Routes chat requests across 5 free-tier providers (OpenRouter, freeinference.org, Groq, NVIDIA NIM, Cloudflare Workers AI) with automatic failover
- Semantic response cache (TF-IDF cosine, SQLite-backed) — near-duplicate prompts hit cache
- Per-provider quota tracking — skips exhausted providers before the 429
- Multi-key rotation per provider
- Usage dashboard — per-provider calls/errors/latency/tokens + cache savings (`usage` CLI, `/usage` endpoint)
- Quota status endpoint — live per-provider free-tier headroom (`quota` CLI, `/quota` endpoint)
- Agent loop with role-based tool restrictions (scout/builder/verifier/reporter)
- Eval suites and load-testing tools
- 147 unit tests including failure injection

## Key commands
- `python src/ai_failover.py "prompt"` — one-shot chat with failover
- `python -m src.loomweaver providers` — list providers
- `python -m src.loomweaver agent "<goal>"` — run the agent
- `python -m src.loomweaver eval --suite <name>` — run evals
- `docker compose up && curl localhost:8080/health` — containerized
