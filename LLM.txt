# flippy — LLM.txt

flippy is a free-first multi-provider LLM inference router with an integrated
agent harness (Loomweaver). Pure Python stdlib; optional litellm for multimodal.

## Capabilities
- Automatic failover across OpenRouter, freeinference.org, Groq, NVIDIA NIM, Cloudflare Workers AI
- Provider pinning via `provider/model` syntax; exact model-ID matching
- Autonomous agent loop with tool registry (shell, http, filesystem, memory)
- Eval suites: basic, reasoning, extraction, tool-selection accuracy
- Inference load testing: concurrency, p50/max latency, tokens/sec, streaming TTFT
- Local cron scheduler for recurring evals and load tests
- JSONL event logging for every run (replayable)

## Key commands
- `python src/ai_failover.py "prompt"` — one-shot chat with failover
- `python -m src.loomweaver providers` — list providers
- `python -m src.loomweaver agent "<goal>"` — run the agent
- `python -m src.loomweaver eval --suite <name>` — run evals
- `python -m src.loomweaver loadtest --provider <name>` — load test
- `python -m src.loomweaver ttft` — streaming latency sweep
